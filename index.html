02 / Choose a platform

Pages or Workers?

Both can serve web projects. The best choice depends on whether your app is static, server-rendered or needs backend features.

Cloudflare Pages

Good for straightforward static websites, static framework output, and existing Pages projects. Pages Functions can add server-side endpoints.

Official Pages docs ↗

Cloudflare Workers

Good for APIs, dynamic request handling, full-stack apps and static assets with server logic. Cloudflare recommends Workers for new projects needing broader capabilities.

Official Workers docs ↗

Remember: a static website does not automatically gain a backend just because it is hosted on Cloudflare. Forms, authentication and private data usually need a secure server-side service or trusted third-party provider.

05 / Before launch

Small checks prevent big problems

  • Test on a phone and a desktop browser.
  • Check every route, image, stylesheet and JavaScript file.
  • Do not put API secrets in frontend code or public Git history.
  • Test forms and error states; do not assume a form works because it looks correct.
  • Connect the custom domain and verify HTTPS before sharing it widely.
  • Keep a copy of the working source and read deployment logs when something fails.
